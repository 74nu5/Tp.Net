# Tp.Net

Travaux pratiques d'onboarding .NET pour l'alternant de 3B Studio.

## Planification

[`planning/plan-tp.html`](planning/plan-tp.html) est le planificateur interactif du cursus :

- **Cursus** : 22 TP en deux phases (socle .NET 10 / 11 et Blazor, puis bonnes pratiques 3B Studio), chacun avec objectifs, notions, pont depuis Java / Rust / JS, point de départ et livrable ;
- **Statut de rédaction** de chaque TP (à cadrer → en rédaction → en relecture → prêt → réalisé) et alerte quand un TP n'est pas prêt à moins de 3 jours de sa date ;
- **Calendrier** calculé par demi-journée à partir de la date d'arrivée, des jours en entreprise et des périodes d'école ;
- **Export** du plan en Markdown ou JSON.

Ouvert directement dans un navigateur, le fichier enregistre les modifications dans le `localStorage`. Publié en artefact Claude, il utilise une base partagée par l'équipe.
