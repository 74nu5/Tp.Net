# Tp.Net

Travaux pratiques d'onboarding .NET pour l'alternant de 3B Studio.

## Planification

[`planning/plan-tp.html`](planning/plan-tp.html) est le planificateur interactif du cursus :

- **Cursus** : 4 demi-journées de manipulation pour donner un vernis global sur .NET 10 / 11 (langage et outillage, serveur web et données, Blazor x 2), une 5ᵉ en bonus (débogage dans une appli existante), puis 2 demi-journées « bonnes pratiques 3B Studio » dans un second temps ;
- chaque demi-journée enchaîne des **exercices courts et minutés**, avec les notions, un pont depuis Java / Rust / JS, un point de départ et un livrable ;
- **Statut de rédaction** de chaque TP (à cadrer → en rédaction → en relecture → prêt → réalisé) et alerte quand un TP n'est pas prêt à moins de 3 jours de sa date ;
- **Calendrier** calculé sur les créneaux réservés aux TP (les matinées par défaut, les après-midi restant aux anomalies), en tenant compte des jours en entreprise et des périodes d'école ;
- **Export** du plan en Markdown ou JSON.

Ouvert directement dans un navigateur, le fichier enregistre les modifications dans le `localStorage`. Publié en artefact Claude, il utilise une base partagée par l'équipe.
