# TP-01 · Tour de .NET et C# express

L'énoncé est interactif : ouvrez **[`enonce.html`](enonce.html)** dans un navigateur (double-clic sur le fichier après avoir cloné le dépôt).

- `depart/` : le point de départ, à ouvrir dans votre IDE (`depart/Katas.slnx`).
- `solution/` : la correction commentée.
- `NOTES-FORMATEUR.md` : les notes pour animer la séance.

Valider le TP, depuis ce dossier :

```bash
dotnet build depart/Katas.slnx                 # 0 avertissement
dotnet test --solution depart/Katas.slnx       # tous les tests au vert
```
